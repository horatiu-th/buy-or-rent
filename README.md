# Cumpăr sau închiriez?

A buy-vs-rent calculator for Romania. It simulates, month by month, the net worth of someone who buys a home against someone who rents a similar one and invests the difference, and shows the rent at which buying starts to pay off.

All inputs are editable, and every scenario can be shared as a link. The interface is in Romanian.

## Data

Defaults come from public sources: BNR (exchange rate, IRCC), the Fiscal Code, notary and land-registry fee schedules, bank product sheets, and published listing-price reports. Each source and every estimate is documented in [`data/SOURCES.md`](data/SOURCES.md).

- `data/overrides.json`: values maintained by hand.
- `data/auto.json`: values written by the weekly data workflow (currently the BNR exchange rate).
- `src/data/defaults.json`: the two merged, generated by `npm run data:merge`. Overrides win.

The weekly workflow opens a pull request when a value changes, so nothing reaches the live site without review.

## Development

Requires Node 24 (see `.nvmrc`).

```
npm ci
npm run dev        # local dev server
npm test           # unit and UI tests
npm run build      # production build in dist/
npm run data:fetch # refresh data/auto.json from BNR
npm run data:merge # rebuild src/data/defaults.json
```

The calculation engine in `src/engine` is plain TypeScript with no UI dependencies.

## Disclaimer

The results depend on assumptions about future prices, rents, rates and returns. They are not financial advice.
